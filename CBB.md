# CBB - could be better

Polish and nice-to-haves parked for later. Not the plan, never blocks current work.
Blast through some when bored or before a big release.

How it works (full rule in the global CLAUDE.md, "CBB.md" section):

- "add X to cbb" appends an entry here. Agents suggest, the owner says yes.
- Browse by listing headers only: search for `^## CBB-`, then read just the one entry.
- Use `## CBB-<n> · <area> · <short title>`, then `added <date>`, a verbatim
  `> owner:` quote, and agent notes. Numbers only go up: next is highest + 1.
- When one lands, delete it here in the same commit and put `CBB-<n>` in the message.
- Promoting one into the project's plan moves it: delete here, note the new id there.
